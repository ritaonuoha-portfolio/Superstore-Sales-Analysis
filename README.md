# Superstore-Sales-Analysis
Interactive Power BI dashboard analysing retail sales, product profitability, regional performance, managers, and customers across three pages. Built using Power BI, Power Query, and DAX to support data-driven business decisions.
# Superstore Sales Analysis

## Project Overview

The Superstore Sales Analysis project uses Power BI to explore retail business performance through an interactive, three-page dashboard. The project focuses on sales performance, product profitability, regional performance, manager performance, and customer analysis.

The goal is to organise retail data into meaningful visualisations that make business performance easier to understand and help decision-makers identify areas that may require attention.

## Project Objectives

- Analyse overall retail sales performance.
- Examine product performance and profitability.
- Explore differences in performance across regions.
- Review manager and customer performance.
- Present business information through interactive dashboards.
- Support data-driven decision-making through clear visualisations.

## Tools and Technologies

- **Power BI:** Dashboard development and data visualisation.
- **Power Query:** Data preparation and transformation.
- **DAX:** Measures and calculations for analysing business performance.
