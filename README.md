# Superstore Sales Analysis

An interactive three-page Power BI dashboard analysing retail sales, product profitability, regional performance, managers, and customers.

## Dashboard Pages

1. **Executive Sales Overview**
2. **Product and Profitability Analysis**
3. **Regional Manager and Customer Performance**

## Tools Used

- Power BI
- Power Query
- DAX

## Project Objective

To explore retail business performance and present insights through interactive dashboards that support data-driven decision-making.
